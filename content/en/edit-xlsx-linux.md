Linux users already have LibreOffice Calc, OnlyOffice Desktop, WPS, and browser options like Google Sheets or Excel for the web. This site is for the middle case: you want spreadsheet fidelity close to Office formats, you do not want to install another suite right now, and you would rather not upload the file.

The editor loads in Firefox or Chrome, reads the file into the tab, and lets you edit and download. Install LibreOffice later if you need a full offline suite; use this when the job is "open the mail attachment and fix a cell."

## What you can do

- Open **.xlsx** (and .xls, .csv) in Firefox or Chrome
- Avoid Wine / Windows VMs for light spreadsheet work
- Keep local editing free and account-free
- Compare with a full desktop suite only when you need macros or heavy models
- Optionally sync workbooks for $5/year across machines

## How it works

1. Open this page in Firefox or Chrome.
2. Click **Open .xlsx on Linux** and choose the file.
3. Edit formulas and formatting in the tab.
4. Download the result, or sign in for optional cloud sync.

## What this is not

If you need VBA, complex pivot caches, or always-offline desktop workflows with deep Calc features, install LibreOffice, OnlyOffice Desktop, or SoftMaker. This page targets quick, install-free edits with good OOXML fidelity.

## Frequently asked questions

### Is this better than LibreOffice Calc?

Different job. LibreOffice is a full desktop suite. This is a zero-install browser editor for `.xlsx` attachments. Many Linux users keep both.

### Does it work in Firefox?

Yes. Use a current Firefox or Chromium-based browser. Large workbooks are limited by your machine's RAM.

### Do my files leave the machine on the local path?

No. Local open stays in the browser tab. Cloud sync is opt-in after sign-in.

### Can I self-host?

Yes. The project is open source and can be served as static files — see the help page on self-hosting.

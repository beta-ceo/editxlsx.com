On a Chromebook, the practical options for Excel files are usually Excel for the web (Microsoft account), Google Sheets (upload + Google account), or an Android Office app with its own limits. This editor adds a fourth path: load OnlyOffice into Chrome as WebAssembly and edit the file **on the device** for free.

That matters on shared school Chromebooks, travel machines, and any ChromeOS device where you would rather not sign into Microsoft or upload a sensitive sheet to a converter.

## What you can do

- Open **.xlsx** attachments from Files or Downloads in Chrome
- Edit cells and formulas without installing Windows Office
- Keep local editing free and account-free
- Install as a PWA for offline use after the first visit
- Optionally sync to your account for $5/year when you need the same file on a phone or another laptop

## How it works

1. Open this page in Chrome on the Chromebook.
2. Click **Open .xlsx on this Chromebook** and pick the file from Files / Downloads.
3. Edit in the browser tab.
4. Download the updated workbook, or sign in later for cloud sync.

## What this is not

Chromebook-friendly does not mean "every Excel feature." VBA macros, heavy Power Query models, and live multi-user co-editing still belong in Excel or Google Sheets. This tool is for opening the attachment, fixing the numbers, and moving on.

## Frequently asked questions

### Can I edit Excel on a Chromebook without Office?

Yes. This editor runs in Chrome. Desktop Office is not required for everyday `.xlsx` edits.

### Does the file upload to a server on the local path?

No. Local open processes the workbook in your browser. Sign in only if you choose optional cloud sync.

### Will it work offline?

After the first visit, you can install it as a PWA and keep editing local files without the network. Font-heavy first opens may still need one online fetch.

### What about Android Excel apps from the Play Store?

Those can work for some files. This page is for people who want a full browser spreadsheet engine without juggling another Microsoft or Google login for a quick edit.

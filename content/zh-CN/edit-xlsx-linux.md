Linux 用户已有 LibreOffice Calc、OnlyOffice 桌面版、WPS，以及 Google 表格 / Excel 网页版等浏览器选项。本站面向中间场景：你要接近 Office 格式的表格保真，此刻不想再装一套，也不想上传文件。

编辑器在 Firefox 或 Chrome 里加载，把文件读进标签页，允许编辑与下载。若需要完整离线套件，以后再装 LibreOffice；本页解决的是「打开邮件附件、改一格」这类活。

## 你能做什么

- 在 Firefox 或 Chrome 打开 **.xlsx**（以及 .xls、.csv）
- 轻量表格工作避开 Wine / Windows 虚拟机
- 本地编辑保持免费、无需账号
- 只有需要宏或重型模型时，再对比完整桌面套件
- 可选每年 $5 跨机器同步工作簿

## 怎么用

1. 用 Firefox 或 Chrome 打开本页。
2. 点击**在 Linux 上打开 .xlsx**并选择文件。
3. 在标签页里改公式与格式。
4. 下载结果；若需要可选云同步再登录。

## 它不适合什么

若你需要 VBA、复杂数据透视缓存，或永远离线、深度依赖 Calc 的桌面工作流，请安装 LibreOffice、OnlyOffice 桌面版或 SoftMaker。本页面向零安装、OOXML 保真度够用的快速编辑。

## 常见问题

### 比 LibreOffice Calc 更好吗？

定位不同。LibreOffice 是完整桌面套件；这是零安装的浏览器编辑器，用来处理 `.xlsx` 附件。很多 Linux 用户两者都留着。

### Firefox 能用吗？

能。请使用较新的 Firefox 或 Chromium 系浏览器。超大工作簿受本机内存限制。

### 本地路径下文件会离开这台机器吗？

不会。本地打开留在浏览器标签页。云同步需登录后主动开启。

### 能自托管吗？

能。项目开源，可按静态站点部署——见帮助页中的自托管说明。
